# A Little World Made for You

Everything personal: `src/content/gift.ts`. Photos: `public/images/` (see README.txt there). Colours: top of `src/app/globals.css`.

```bash
npm install
npm run dev      # http://localhost:3000   (add #garden, #letter … to jump to a chapter while editing)
npm run build    # static site in ./out — upload that folder anywhere
```
